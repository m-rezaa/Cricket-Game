# 🏏 Cricket Game

A console-based Cricket Game developed in **C** that simulates a simplified cricket match through interactive gameplay and programmed game logic.

## 📌 Overview

The Cricket Game allows players to participate in a simulated cricket match through a command-line interface. The application handles scoring, gameplay progression, and match outcomes using C programming concepts and structured logic.

## ✨ Features

* Interactive console-based gameplay
* Cricket match simulation
* Score tracking
* Batting and scoring logic
* Match progression and result calculation
* User input handling
* Dynamic game outcomes

## 🛠️ Technologies Used

* **C Programming**
* **Standard C Libraries**
* **Console / Command-Line Interface**

## 🎯 Concepts Demonstrated

* Variables and data types
* Conditional statements
* Loops and control structures
* Functions
* Arrays
* User input handling
* Random number generation
* Structured programming
* Game logic implementation

## 🚀 Purpose

This project was developed to strengthen C programming fundamentals and demonstrate how programming logic can be applied to create an interactive command-line game.
